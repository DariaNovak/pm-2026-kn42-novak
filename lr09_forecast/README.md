## 2. Як рахувалася симуляція

| Поле | Значення |
| --- | --- |
| Інструмент | власний скрипт Python, `lr09_forecast/simulate.py` |
| Прогонів | 10 000, зерно генератора 42 (прогін повторюваний) |
| Що тягнеться випадково | velocity одного зі спринтів історії (`points_done`), з поверненням |
| Як рахується дата прогнозу | останній день спринта, на якому закінчується робота: для сценарію «весь перший реліз» кінець спринта 1 плюс (P − 1) × 14 днів, для сценарію залишку кінець останнього спринта плюс P × 14 днів |

Одна симуляція: беремо обсяг; поки він більший за нуль, `random.choice` тягне
одну velocity з історії, віднімає її від обсягу і додає спринт. Коли обсяг дійшов
до нуля або нижче, записуємо кількість спринтів. 10 000 таких чисел сортуємо;
P50 це найменше число, нижче або на рівні якого лежить 50% результатів, P85 те
саме для 85% (`sorted[ceil(q × N) − 1]`). Результат уже цілий, бо рахуються цілі
спринти, тому округлення вгору виходить саме собою. Захист від нескінченного
циклу: якщо історія складається з самих нулів, цикл обривається на 1000
спринтів.

Запуск:

```bash
python lr09_forecast/simulate.py 220 --csv lr09_reference_velocity.csv
python lr09_forecast/simulate.py 220 --csv lr09_reference_velocity.csv --sprints 1,2
python lr09_forecast/simulate.py 220 --csv lr09_reference_velocity.csv --sprints 5,6
# після спринта 2, на власних даних:
python lr09_forecast/simulate.py <points> --csv lr09_forecast/velocity.csv
```

Ядро скрипта:

```python
for _ in range(runs):
    left, sprints = points, 0
    while left > 0:
        left -= rng.choice(history)
        sprints += 1
    results.append(sprints)
results.sort()
p50 = results[math.ceil(0.50 * len(results)) - 1]
p85 = results[math.ceil(0.85 * len(results)) - 1]
```

спринти схожі між собою. Спринти 1 і 2 (21 і 17) майже однакові, тому інтервал

12 points, яких ця пара просто не бачила. Спринти 5 і 6 (23 і 6) дали протилежне:
інтервал ширший і зсунутий на три-шість спринтів вправо, бо один поганий спринт
у вибірці з двох це половина всієї історії. Отже вузький інтервал на двох
спринтах це не точність, а мала вибірка: він каже лише про те, що два числа
випадково близькі, і саме тому мій власний прогноз після двох спринтів я
називатиму з P85 і перераховуватиму після кожного наступного спринта.
